- 💡 I'm passionate about building robust systems using Clean Architecture, Domain-Driven Design (DDD), and CQRS patterns.
- 🔭 I’m currently working on Project Facto (a serverless multi-tenant electronic billing SaaS built in Go) and my own open-source Go invoice library.
- 🌱 I’m currently learning advanced techniques for building open-source Go libraries and sharpening my advanced English communication skills.
- 🤔 I’m looking for help with exploring new optimization patterns for multi-tenant PostgreSQL databases and advanced GCP Cloud Run outbox implementations.
